# 지도 API 기반 경로 추천 알고리즘 프로젝트

## 1. 프로젝트 방향

지도 API를 활용해 지도와 도로 데이터를 가져오고, **핵심 경로 추천 로직은 직접 구현**하는 프로젝트를 진행한다.

목표는 단순히 지도 API를 사용하는 것이 아니라 다음 내용을 직접 이해하는 것이다.
- HTTP 요청과 응답이 어떻게 이루어지는지
- JSON 데이터를 어떻게 처리하는지
- 지도 데이터를 어떤 구조로 표현하는지
- 경로 추천 알고리즘이 어떻게 동작하는지
- 사용자 조건에 따라 최적 경로를 어떻게 선택하는지

---

## 2. 추천 프로젝트 주제

### 사용자 조건 기반 최적 경로 추천 시스템

사용자가 출발지와 목적지를 입력하고 원하는 조건을 설정하면, 여러 경로를 비교하여 적합한 경로를 추천하는 시스템이다.

예시:

- 출발지: 구미역
- 목적지: 금오산
- 조건:
  - 최단시간
  - 최단거리
  - 통행료 최소
  - 종합적인 최적 경로

전체 구조:

```text
[사용자 입력]
     ↓
출발지 / 목적지 / 조건
     ↓
[지도 API]
     ↓
도로 정보 + 경로 정보
     ↓
[직접 구현한 알고리즘]
     ↓
각 경로의 비용 계산
     ↓
최적 경로 선택
     ↓
[지도에 결과 표시]
```

---

## 3. 프로젝트를 단계적으로 발전시키기

## LEVEL 1 — 지도 API 사용

가장 먼저 지도 API에서 경로 데이터를 가져오는 것부터 구현한다.

```text
주소 입력
   ↓
좌표 변환
   ↓
지도 API 요청
   ↓
거리 / 시간 / 경로 정보 출력
```

### 학습 목표

- API의 개념
- API Key의 역할
- HTTP 요청
- GET/POST 방식
- JSON 구조
- API 응답 데이터 처리

간단한 형태:

```python
start = "구미역"
end = "금오산"

route = get_route(start, end)

print(route)
```

처음부터 복잡한 알고리즘을 구현하기보다 **API에서 데이터를 가져오는 과정 자체를 이해하는 것**이 중요하다.

---

# LEVEL 2 — 여러 경로 비교

지도 API에서 여러 경로를 제공한다면 각 경로를 비교한다.

예시:

| 경로 | 거리 | 예상시간 | 통행료 |
|---|---:|---:|---:|
| A | 15km | 25분 | 0원 |
| B | 12km | 30분 | 1,000원 |
| C | 18km | 20분 | 2,000원 |

단순하게 가장 짧은 거리나 가장 빠른 시간을 선택하는 것부터 시작한다.

예:

```python
best_route = min(routes, key=lambda route: route["distance"])
```

### 학습 목표

- 리스트와 딕셔너리
- 반복문
- 조건문
- 정렬
- `min()`, `max()`
- 함수 작성
- API 응답 데이터 가공

---

# LEVEL 3 — 사용자 선호도 반영

사용자가 무엇을 중요하게 생각하는지 반영한다.

예:

```text
○ 가장 빠른 길
○ 가장 짧은 길
○ 통행료가 적은 길
○ 종합적으로 좋은 길
```

각 요소에 가중치를 부여하여 점수를 계산한다.

### 기본적인 점수 계산

```python
score = (
    distance * distance_weight
    + time * time_weight
    + toll * toll_weight
)
```

예를 들어 시간 중심의 사용자는:

```python
score = (
    distance * 0.2
    + time * 0.7
    + toll * 0.1
)
```

비용을 중요하게 생각하는 사용자는:

```python
score = (
    distance * 0.3
    + time * 0.2
    + toll * 0.5
)
```

처럼 가중치를 다르게 설정할 수 있다.

### 핵심 개념

**같은 경로라도 사용자의 목적에 따라 추천 결과가 달라질 수 있다.**

---

# LEVEL 4 — 직접 경로 탐색 알고리즘 구현

프로젝트의 알고리즘적인 부분을 강화한다.

도로를 그래프(Graph)로 생각한다.

```text
A ─ B ─ C
│   │   │
D ─ E ─ F
    │
    G
```

여기서:

```text
교차로 = Node
도로 = Edge
거리 / 시간 = Weight
```

로 생각할 수 있다.

### 공부할 알고리즘

추천 순서:

1. BFS
2. DFS
3. Dijkstra
4. A*

특히 **Dijkstra → A*** 순서로 공부하는 것을 추천한다.

---

## Dijkstra의 기본적인 개념

출발점에서 다른 지점까지의 비용을 계산하면서 가장 비용이 작은 지점을 차례로 선택한다.

```text
출발지
 ↓
주변 노드 탐색
 ↓
각 도로의 비용 계산
 ↓
가장 비용이 작은 노드 선택
 ↓
다시 주변 노드 탐색
 ↓
목적지 도착
```

이 과정을 직접 코드로 구현하면 경로 탐색 알고리즘을 이해하는 데 큰 도움이 된다.

# LEVEL 5 — 최종 프로젝트

최종적으로 다음과 같은 시스템을 목표로 한다.

## 사용자 선호도 기반 다목적 경로 추천 시스템

### 사용자 입력

```text
출발지: 구미역
목적지: 금오산

[시간 중요도] ███████░░░
[거리 중요도] ████░░░░░░
[비용 중요도] ██░░░░░░░░
```

### 처리 과정

```text
지도 API
   ↓
도로 / 경로 데이터
   ↓
Graph 구성
   ↓
경로 탐색
   ↓
각 경로의 비용 계산
   ↓
사용자 가중치 적용
   ↓
최적 경로 선정
```

### 결과 예시

```text
추천 경로

예상 시간: 24분
거리: 14.2km
통행료: 0원

추천 이유:
시간과 통행료를 중요하게 설정한 조건에서
해당 경로의 종합 점수가 가장 낮게 계산되었습니다.
```

# 5. AI는 언제 사용하는가?

처음부터 AI를 넣는 것보다는 **기본 알고리즘을 먼저 직접 구현하는 것**을 추천한다.

먼저:

```text
지도 API
+
Python
+
자료구조
+
Graph
+
Dijkstra
+
A*
```

를 이용해 기본 시스템을 완성한다.

그 후 AI를 추가할 수 있다.

예:

```text
사용자의 과거 선택
        ↓
선호도 분석
        ↓
가중치 자동 조정
        ↓
개인화된 경로 추천
```

이렇게 발전시키면 단순한 API 프로젝트에서 **개인화된 경로 추천 시스템**으로 확장할 수 있다.

# 7. 추천 개발 순서

실제 프로젝트는 다음 순서로 진행한다.

```text
1. 지도 API 선택
        ↓
2. API Key 발급
        ↓
3. Python에서 API 호출
        ↓
4. JSON 응답 구조 분석
        ↓
5. 거리 / 시간 / 비용 데이터 추출
        ↓
6. 여러 경로 비교
        ↓
7. 사용자 가중치 적용
        ↓
8. 그래프 자료구조 공부
        ↓
9. Dijkstra 직접 구현
        ↓
10. A* 알고리즘 공부 및 구현
        ↓
11. 지도에 추천 경로 표시
        ↓
12. 사용자 선호도 기반 추천 시스템 완성
```

# 8. 프로젝트의 핵심 목표

이 프로젝트에서 가장 중요한 것은 **완성된 코드를 가져다 사용하는 것보다 코드가 왜 그렇게 동작하는지 이해하는 것**이다.

따라서 다음과 같은 방식으로 진행하는 것이 좋다.

```text
API 사용법 복사
        ↓
코드 실행
        ↓
각 코드가 무엇을 하는지 분석
        ↓
직접 수정
        ↓
오류 발생
        ↓
오류 원인 분석
        ↓
직접 기능 추가
```

특히 경로 추천 알고리즘은 라이브러리에서 그대로 가져오기보다는 **Dijkstra와 A*의 핵심 부분을 직접 구현**하는 것을 목표로 한다.

# 9. 최종적으로 얻을 수 있는 것

프로젝트를 완성하면 다음 내용을 하나의 프로젝트 안에서 경험할 수 있다.

- Python 프로그래밍
- REST API 사용
- JSON 데이터 처리
- 지도 API 활용
- 데이터 전처리
- 자료구조
- Graph
- 최단 경로 알고리즘
- Dijkstra
- A*
- 가중치 기반 최적화
- 사용자 맞춤 추천
- 지도 시각화

즉, 단순히 **"지도 API를 사용해 경로를 표시하는 프로젝트"**가 아니라,

> **지도 API로 데이터를 받아오고 → 그래프로 구조화하고 → 직접 만든 알고리즘으로 경로를 탐색하고 → 사용자 조건에 따라 최적 경로를 추천하는 프로젝트**

로 만드는 것이 핵심이다.
